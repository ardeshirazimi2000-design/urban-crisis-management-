# اپ امدادگر (Flutter، offline-first)

فهرست مأموریت‌ها (کش رمزنگاری‌شده)، تغییر وضعیت مأموریت (دریافت، در مسیر، در محل، تکمیل) و ارسال موقعیت
در حالت آفلاین؛ همگام‌سازی به‌ترتیب و idempotent. سرور مرجع نهایی است: اگر فرمانده مأموریت را لغو کرده باشد
تغییر آفلاین به‌صورت «تعارض» نمایش داده می‌شود و تحمیل نمی‌شود (AT-12).

```bash
flutter pub get
flutter test
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080/api/v1
```
