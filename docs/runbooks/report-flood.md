# Runbook: سیل گزارش (جعلی یا واقعی)

1. نرخ `POST /api/v1/reports` و 429ها را در داشبورد ببینید؛ تفکیک کنید: زلزله واقعی (پراکندگی جغرافیایی واقعی) یا حمله (تمرکز روی چند حساب/الگوی متنی).
2. محدودیت در دو لایه است: Ingress (`limit-rpm`) و سرویس (`RATE_REPORT_PER_MIN` به‌ازای هر کاربر). کلید محدودیت هویت است نه IP (CGNAT).
3. حمله: حساب‌های مشکوک را با `POST /admin/users/{id}/status` معلق کنید (دلیل الزامی). گزارش‌ها حذف نمی‌شوند؛ رد با دلیل.
4. رویداد واقعی: ظرفیت اپراتور را افزایش دهید؛ از فیلتر «گزارش‌های نزدیک» و «احتمال تکرار» برای ادغام استفاده کنید؛ AI فقط اولویت‌بندی کمکی است.
