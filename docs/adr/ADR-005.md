# ADR-005: هشدار عمومی با گردش کار تأیید و ممیزی

وضعیت: پذیرفته‌شده (MVP)

## زمینه
ارسال مستقیم از Rule Engine خطر هشدار کاذب یا تکراری دارد.

## تصمیم
draft → pending_approval → approved → sending → sent/partially_sent/failed؛ تأیید چهارچشمی، انقضای الزامی، قالب نسخه‌دار، پیش‌نمایش دقیق، dispatch idempotent، پیام آزمایشی با برچسب «آزمایشی»، رد dispatch بدون تأیید به‌عنوان رویداد امنیتی.

## پیامد
پذیرش ارائه‌دهنده با تحویل یکی نیست؛ وضعیت هر کانال مستقل نگهداری می‌شود.
