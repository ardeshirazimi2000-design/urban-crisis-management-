# ADR-002: PostgreSQL + PostGIS منبع حقیقت دامنه

وضعیت: پذیرفته‌شده (MVP)

## زمینه
گزارش، حادثه، منبع و هشدار نیازمند تراکنش، قیود یکتایی و پرس‌وجوی مکانی‌اند.

## تصمیم
PostgreSQL 16 + PostGIS 3؛ ستون‌های `geography(…,4326)`، ایندکس GiST، `ST_DWithin` با واحد متر.

## پیامد
Elasticsearch، TimescaleDB و Data Lake تا اثبات نیاز اضافه نمی‌شوند.
