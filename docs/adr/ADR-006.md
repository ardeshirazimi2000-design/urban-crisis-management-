# ADR-006: مکان و رسانه با دسترسی حداقلی

وضعیت: پذیرفته‌شده (MVP)

## زمینه
افشای موقعیت دقیق شهروند و رسانه ریسک حریم خصوصی است.

## تصمیم
مختصات دقیق فقط با `report:read_precise`؛ رسانه در storage خصوصی با URL امضاشده ۵ دقیقه‌ای، کنترل MIME واقعی، checksum و وضعیت اسکن؛ رسانه در event bus حمل نمی‌شود؛ صدور URL ممیزی می‌شود.

## پیامد
اسکنر واقعی بدافزار پیش از تولید الزامی است (`MEDIA_ALLOW_UNSCANNED` در تولید رد می‌شود).
